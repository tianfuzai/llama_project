# 效果评估报告（核心文档）

## 1. 测试集构建（FR-F1）

运行 `scripts/build_testset.py`：

- 输出 50 题山西政务问答测试集 `project_data/testset.json`
- 测试集为**人工内置的独立政务题目**（问题 + 参考答案要点），**不取自训练数据**（alpaca_zh.json / sft_data.jsonl），确保与训练数据无重叠、避免数据泄漏

## 2. 三方模型评估（FR-F2）

对「基座模型 / SFT-LoRA 模型 / DPO 模型」在 50 题上分别生成回答，运行 `scripts/evaluate.py`：

- 基座：Qwen2.5-1.5B-Instruct
- SFT：`saves/sft_exp1`（LoRA）
- DPO：`saves/dpo`（LoRA）

输出文件：

- `evaluation_results.json`：三方回答结果
- `evaluation_manual.csv`：人工打分表（准确性/专业性/格式规范性）
- `evaluation_llm_prompt.txt`：大模型打分提示词模板

## 3. 打分方式（FR-F2）

**人工打分**：从准确性、专业性、格式规范性三个维度打分（1-5），填入 `evaluation_manual.csv`。

**大模型打分**：用 `evaluation_llm_prompt.txt` 提示词让强模型对三模型回答对照评分，并与人工结果做一致性比对。
