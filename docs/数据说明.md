# 数据说明

## 1. 领域资料清单

| 资料类型 | 来源 | 获取方式 |
|---|---|---|
| 山西政务服务办事指南 | 山西政务服务网（sxzwfw.gov.cn）公开办事指南 | `crawl_shanxi.py` 爬虫抓取 |
| 原始文本 | 抓取结果合并 | `project_data/raw_docs/all_raw_text.txt`（≈298KB） |
| 文本分块 | 清洗 + 滑动窗口分块（512字/重叠64） | `clean_and_chunk.py` → `chunks.txt`（623块） |

> 数据来源真实可溯源，全部来自山西政务服务网公开信息，未凭空编造。

## 2. QA 抽取提示词模板

`auto_gen_sft.py` 中 `build_prompt`，调用本地 Ollama `qwen2.5:7b` 从 chunk 抽取 QA：

```
你是政务领域数据标注专家。根据下面的政务原文，生成1条高质量的问答对。
要求：
1. instruction：从办理流程与操作步骤的角度提问（基于原文，不编造）
2. output：使用原文内容简洁准确回答，不要额外编造
3. 输出严格是JSON，只有instruction和output两个字段
```

每个 chunk 从三个角度各生成 1 条：办理流程、所需材料、办理时限与政策，避免同 chunk 高度重复。

## 3. 数据规模

| 数据集 | 条数 | 格式 | 文件 |
|---|---|---|---|
| 蒸馏原始 QA | ≥500 | Alpaca(instruction/input/output) | `sft_data.jsonl` |
| 清洗后 Alpaca | ≥500 | Alpaca | `alpaca_zh.json` |
| ShareGPT | ≥500 | messages 多轮 | `sharegpt_zh.json` |
| DPO 偏好配对 | ≥200 组 | messages+chosen/rejected | `dpo_data.json` |
| 测试集 | ≥50 题 | question/answer | `testset.json` |

## 4. 清洗规则（FR-A5）

运行 `scripts/clean_sft_data.py`：

1. 去空：instruction 或 output 为空则剔除
2. 去重：instruction+output 完全相同则剔除
3. 过滤答案过短（<10字）或过长（>800字）
4. 统一全半角标点、压缩空白

清洗统计见 `project_data/clean_report.txt`。

## 5. 人工抽检（FR-A4）

运行 `scripts/sample_check.py` 随机抽取 50 条生成抽检表 `project_data/sample_check_50.csv`，人工对照原文填写三列判定：

- 与原文一致率（目标 ≥90%）
- 答案可用率
- 格式合规率

> 抽检表判定列由小组成员人工填写后回填统计。
