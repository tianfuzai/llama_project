# 训练实验报告（核心文档）

## 1. 实验环境

- 基座模型：Qwen/Qwen2.5-1.5B-Instruct
- 训练框架：LLaMA-Factory
- GPU 显存：≥8GB（1.5B + LoRA 规格）
- 数据集：`shanxi_alpaca`（alpaca_zh.json）

## 2. 四组超参对比实验（FR-C2）

| 实验 | LoRA rank | LoRA alpha | 学习率 | epochs | batch | grad accum | cutoff | 变量意图 |
|---|---|---|---|---|---|---|---|---|
| Exp1(基准) | 8 | 16 | 2e-5 | 3 | 1 | 4 | 1024 | 基准组 |
| Exp2 | 16 | 32 | 2e-5 | 3 | 1 | 4 | 1024 | 对比 rank 增大 |
| Exp3 | 8 | 8 | 2e-5 | 3 | 1 | 4 | 1024 | 对比 alpha 同比例 |
| Exp4 | 8 | 16 | 1e-4 | 3 | 1 | 4 | 1024 | 对比学习率增大 |

覆盖变量：**rank**（8 vs 16）、**alpha**（同比例16 vs 不同比例8）、**学习率**（2e-5 vs 1e-4）。

运行命令：

```bash
python run_train.py train_config/sft_exp1.yaml
python run_train.py train_config/sft_exp2.yaml
python run_train.py train_config/sft_exp3.yaml
python run_train.py train_config/sft_exp4.yaml
```

每组实验独立输出到 `saves/sft_expN`，日志记录 train loss 与 val loss，用于绘制 loss 曲线。

## 3. 参数取值理由（FR-C3）

- **epochs=3**：数据量适中，3 轮兼顾拟合与防止过拟合
- **batch_size=1 + grad_accum=4**：显存受限下用小 batch，用梯度累积模拟等效 4 的 batch
- **cutoff_len=1024**：覆盖大多数问答长度，平衡截断与显存
- **fp16**：1.5B 模型 fp16 可运行，显存友好
- **lr_scheduler=cosine + warmup 0.05**：稳定训练、缓解前期震荡
- **seed=42**：保证实验可复现

> 每组的 train/val loss 曲线数据从对应输出目录日志导出，此处留待实验完成后填写具体 loss 数值与过拟合判断。

## 4. 显存降级试验记录（FR-C4）

当显存不足时按以下优先级降级（记录实际采用手段与效果）：

1. 降低 `cutoff_len`（1024 → 512）
2. 减小 batch_size 并调大 `gradient_accumulation_steps`
3. 改用 QLoRA 4bit（`quantization_bit: 4`）
4. 削减 `max_samples`
5. 换更小基座模型

## 5. LoRA 体积对比（FR-C5）

运行 `scripts/compare_size.py`：

- 基座模型 Qwen2.5-1.5B-Instruct：约 3GB

> 具体数字由脚本运行后回填，验证 LoRA 轻量化特点。
