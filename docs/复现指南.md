# 复现指南

本指南帮助另一组同学在同等硬件（8GB 显存 + Qwen2.5-1.5B + LLaMA-Factory）下复现本项目全部结果。

## 1. 前置条件

- NVIDIA GPU ≥8GB 显存，CUDA
- Python 3.10，conda 环境 `nlpbase`
- Ollama 已安装并拉取 `qwen2.5:7b`（用于数据蒸馏）
- 已下载 Qwen/Qwen2.5-1.5B-Instruct 到本地缓存

## 2. 全流程复现步骤

### 步骤1：环境搭建
按 `docs/部署说明.md` 安装依赖。

### 步骤2：数据准备（随机种子 seed=42 保证可复现）
```bash
python crawl_shanxi.py
python clean_and_chunk.py
python auto_gen_sft.py                    # 每 chunk 3 条，三角度
python scripts/clean_sft_data.py          # 清洗 → alpaca_zh.json（≥500条）
python scripts/convert_to_sharegpt.py     # → sharegpt_zh.json（≥500条）
python scripts/build_dpo_data.py          # → dpo_data.json（≥200组）
python scripts/build_testset.py           # → testset.json（50题）
```

### 步骤3：SFT 超参实验（4 组）
```bash
python run_train.py train_config/sft_exp1.yaml
python run_train.py train_config/sft_exp2.yaml
python run_train.py train_config/sft_exp3.yaml
python run_train.py train_config/sft_exp4.yaml
```
所有配置记录随机种子 `seed: 42`。

### 步骤4：DPO 训练
```bash
python run_train.py train_config/dpo.yaml
```

### 步骤5：推理与评估
```bash
python scripts/infer_peft.py saves/sft_exp1 "问题"
python scripts/compare_size.py
python scripts/evaluate.py
```

## 3. 可复现性保证

- 所有训练配置落盘为 YAML：`train_config/sft_exp1~4.yaml`、`dpo.yaml`
- 统一随机种子 `seed: 42`
- 数据清洗、ShareGPT 转换、DPO 构造、测试集构建均为确定性脚本
- 蒸馏使用本地 Ollama 固定模型 `qwen2.5:7b`，prompt 模板固定

## 4. 预期结果

- alpaca_zh.json / sharegpt_zh.json 各 ≥500 条
- dpo_data.json ≥200 组
- testset.json 50 题
- 4 组 SFT loss 曲线 + DPO loss 曲线
- 三方（基座/SFT/DPO）50 题对比表

## 5. 常见问题

- huggingface 超时：脚本已设 `HF_HUB_OFFLINE=1`
- dataset 未定义：确认 yaml 的 `dataset:` 与 `data/dataset_info.json` 顶层 key 一致
- 显存不足：按部署说明降级顺序调整
