# 部署说明

## 1. 环境要求

- 操作系统：Windows 10 / 11（vLLM 路线需 Linux）
- Python 3.10+
- GPU：NVIDIA，显存 ≥8GB，CUDA
- 训练框架：LLaMA-Factory（含 WebUI）
- 基座模型：Qwen/Qwen2.5-1.5B-Instruct（本地缓存，离线训练）

## 2. 硬件门槛

| 微调方案 | 最低显存 | 本项目 |
|---|---|---|
| Qwen2.5-1.5B + LoRA（bf16） | 8GB | ✔ |

## 3. 安装步骤

```bash
# 创建虚拟环境
conda create -n nlpbase python=3.10
conda activate nlpbase

# 安装 PyTorch（CUDA 版，按驱动选 cu121/cu118）
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121

# 核心依赖
pip install transformers peft accelerate datasets sentencepiece protobuf

# LLaMA-Factory
pip install llamafactory

# 爬虫与数据处理
pip install requests beautifulsoup4
```

> 离线优先：训练脚本已设 `HF_HUB_OFFLINE=1`，读取本地缓存，不请求外网。

## 4. 数据准备命令

```bash
python crawl_shanxi.py                    # 爬取原始文本
python clean_and_chunk.py                 # 清洗 + 分块
python auto_gen_sft.py                    # 蒸馏 QA（需 Ollama qwen2.5:7b）
python scripts/clean_sft_data.py          # 清洗统计 → alpaca_zh.json
python scripts/convert_to_sharegpt.py     # ShareGPT 格式
python scripts/build_dpo_data.py          # DPO 偏好配对
python scripts/build_testset.py           # 50 题测试集
```

## 5. 训练命令

```bash
python run_train.py train_config/sft_exp1.yaml   # 基准组
python run_train.py train_config/sft_exp2.yaml   # rank=16
python run_train.py train_config/sft_exp3.yaml   # alpha=8
python run_train.py train_config/sft_exp4.yaml   # lr=1e-4
python run_train.py train_config/dpo.yaml        # DPO
```

## 6. 推理与评估命令

```bash
python scripts/infer_peft.py saves/sft_exp1 "问题"
python scripts/compare_size.py                   # LoRA 体积对比
python scripts/evaluate.py                       # 三方评估
```

## 7. vLLM 说明（FR-E2）

vLLM 加载 LoRA 并暴露 OpenAI 兼容接口需要 **GPU / Linux 环境**。本项目在 Windows 本机完成，vLLM 路线作为可选；未完成时在文档中说明客观原因，以 PEFT 路线（`PeftModel`）作为替代验证，不影响验收（README 已声明）。

## 8. 显存不足降级顺序

降低截断长度 → 减小 batch 并调大梯度累积 → QLoRA 4bit → 削减 max_samples → 换更小基座。
